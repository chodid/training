# Schriften für Word

Die Vorlage nutzt **Young Serif** (Name, Betreff) und **Source Sans 3** (Fließtext). Beide sind frei (OFL) und müssen einmalig installiert sein, sonst ersetzt Word sie:

Die TTF-Dateien liegen im Design-System unter `fonts/`:

- Young Serif: `fonts/YoungSerif-Regular.ttf` → doppelklicken → Installieren
- Source Sans 3: `fonts/SourceSans3-VariableFont_wght.ttf` und `fonts/SourceSans3-Italic-VariableFont_wght.ttf` → gleich
- Optional Source Code Pro: `fonts/SourceCodePro-VariableFont_wght.ttf`

Alternativ über Google Fonts: https://fonts.google.com/specimen/Young+Serif bzw. https://fonts.google.com/specimen/Source+Sans+3 → „Get font“ → ZIP entpacken → TTF installieren.

Danach Word neu starten. Für Weitergabe an andere: Datei → Optionen → Speichern → „Schriftarten in Datei einbetten“.
